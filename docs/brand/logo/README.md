# مصحف القراءات: دليل الشعار

## 1. الفكرة
صفحة مصحف على حافتها زخرفة الهامش الذهبية، وهي الموضع الذي تُدوَّن فيه فروق القراءات. الشعار يشير إلى لوحة الفروق في التطبيق، والذهبي مأخوذ من تذهيب المصاحف.

## 2. الملفات
| الملف | الاستخدام |
|---|---|
| `symbol.svg` | الرمز الأساسي على خلفية فاتحة (صفحة خضراء + زخرفة ذهبية) |
| `symbol-on-dark.svg` | الرمز على خلفية خضراء أو داكنة (صفحة كريمية) |
| `symbol-small.svg` / `symbol-small-on-dark.svg` | النسخة المبسطة لمقاس 32px وأقل (بلا أسطر ولا نجمة) |
| `app-icon.svg` | أيقونة التطبيق، مربع كامل (iOS وAndroid يقصّان الزوايا بأنفسهما) |
| `app-icon-rounded.svg` | الأيقونة بزوايا مستديرة، للعروض ووسائل التواصل |
| `lockup-horizontal.svg` / `-on-dark.svg` | الاسم مع الرمز أفقيًا |
| `lockup-stacked.svg` | الاسم تحت الرمز |
| `variants/` | نسخ بلون واحد: أسود، أبيض، أخضر |
| `png/` | أيقونة التطبيق 1024/512/192/180/120، والرمز 1024، والتركيبات |
| `web/` | favicon.ico و favicon.svg ومقاسات PNG الصغيرة |
| `board/` | لوحة العرض (`board.html`) وصورها في `slides/` |

## 3. المساحة الخالية
اترك حول الشعار مسافة لا تقل عن **نصف عرض الزخرفة الذهبية** من كل الجهات، وتكبر هذه المسافة وتصغر مع الشعار.

## 4. أصغر مقاس
| النسخة | الشاشة | الطباعة |
|---|---|---|
| التركيبة الأفقية | 140px عرضًا | 35mm |
| الرمز الكامل | 40px | 10mm |
| الرمز المبسط | 16px | 5mm |

## 5. الألوان
| الاسم | HEX | RGB | CMYK (تقريبي) |
|---|---|---|---|
| أخضر المصحف | `#285D4F` | 40, 93, 79 | 57, 0, 15, 64 |
| أخضر داكن (نص الاسم) | `#1E4A3E` | 30, 74, 62 | 59, 0, 16, 71 |
| ذهبي التذهيب | `#C9A54E` | 201, 165, 78 | 0, 18, 61, 21 |
| كريمي الورق | `#FCFAF3` | 252, 250, 243 | 0, 1, 4, 1 |

قيم CMYK تقريبية، فاعتمد بروفة طباعة قبل أي طباعة كبيرة.

**التركيبات المعتمدة:** الألوان الكاملة على أبيض أو كريمي · نسخة `on-dark` على الأخضر · أبيض بلون واحد على صور أو خلفيات داكنة · أسود بلون واحد للطباعة أحادية اللون.

## 6. الخط
- الاسم مكتوب بخط **Amiri Quran** (رخصة OFL، تسمح باستخدامه في الشعارات)، وهو نفس الخط المضمّن في التطبيق.
- «مصحف» بالأخضر الداكن، و«القراءات» بالذهبي.
- **مهم:** النص في ملفات التركيبات SVG نص حي والخط مضمّن فيه، وليس مسارات. قبل الطباعة أو التسليم لمطبعة، افتح الملف في Figma أو Inkscape وحوّل النص إلى مسارات (Outline / Object to Path). ملفات PNG في `png/` جاهزة كما هي.

## 7. تجنّب
لا تمدّ الشعار أو تضغطه · لا تغيّر ألوانه خارج اللوحة · لا تدوّره · لا تضف ظلالًا أو حدودًا أو تدرجات · لا تغيّر مكان أو حجم الرمز بالنسبة للاسم · لا تضعه على خلفية مزدحمة بلا مساحة هادئة · لا تكتب الاسم بخط آخر.

## 8. ملاحظات
- لم يُجرَ بحث عن العلامات التجارية؛ يُنصح ببحث قبل التسجيل أو النشر في المتاجر.
- لتطبيق الأيقونة في المشروع: `png/app-icon-1024.png` هو المصدر المناسب لأداة مثل `flutter_launcher_icons`.
